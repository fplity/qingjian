# 青简 v1.0.0 Debug Preview

`v1.0.0-debug` is Qingjian's first **debug prerelease**. It is a small, fully local Android reader for high-school classical Chinese prose and poetry.

## Included

- Local article browsing with poetry/prose category filters.
- Article metadata, original text, and plain-language translations.
- Local favorites, reading font-size preferences, and light/system reading mode.

## Release asset

This prerelease contains exactly one APK asset:

- `qingjian-v1.0.0-debug.apk`

The asset is generated from the current Debug build output. It is provided for testing only and is not committed to the source repository.

## Important verification status

The project compiles successfully, but complete Android runtime validation on a stable device or emulator—including visual layout, navigation interactions, and persistence checks—remains pending. This release is therefore deliberately marked as a prerelease and must not be treated as a stable or production-ready build.

## Not included

There is no recitation practice, AI, speech recognition, account, cloud sync, network request, backend, database, advertising, or membership feature in this version.
